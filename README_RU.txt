WhatsApp Assistant 2.2

Удалён «Помощник с текстом». Добавлены: документы через системное меню Share, ссылки на место, vCard контакты, подготовка опросов и календарных событий. Создание встроенного опроса/мероприятия WhatsApp невозможно через обычный сайт, это завершается внутри WhatsApp.

Обновление GitHub Pages: распаковать ZIP и загрузить его файлы в корень репозитория поверх предыдущих. Черновики сохранены под прежним ключом localStorage; не стирать данные сайта.
