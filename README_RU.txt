WhatsApp Assistant 2.1 — обновление со смайликами

Все файлы загрузите в корень текущего репозитория GitHub whatsapp-assistant и подтвердите Commit changes. В Settings → Pages должен оставаться main / (root).

В редакторе теперь есть панель «😊 Смайлики» с категориями. Нажатие вставляет эмодзи в позицию курсора или вместо выделенного фрагмента. Смайлики сохраняются в черновиках и передаются в WhatsApp как часть сообщения.

Примечание: приложение не читает переписки, не отправляет сообщения автоматически, не переводит произвольный текст автоматически. При проблемах с обновлением перезапустите установленное веб-приложение или обновите страницу в Safari.
