WhatsApp Assistant — бесплатное мини-приложение для iPhone

Состав: index.html, app.js, style.css, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.

Как опубликовать бесплатно на GitHub Pages:
1. Откройте github.com и войдите/создайте бесплатную учётную запись.
2. Создайте новый публичный репозиторий с названием whatsapp-assistant.
3. Загрузите ВНУТРЬ репозитория все 7 файлов из этой папки (не ZIP и не вложенную папку).
4. Зайдите в Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
5. Дождитесь появления опубликованного адреса в разделе Pages (обычно вида https://ИМЯ.github.io/whatsapp-assistant/).
6. Откройте опубликованный адрес в Safari на iPhone, нажмите кнопку «Поделиться» → «На экран Домой» → «Добавить».

ВАЖНО: Ссылки на шаблоны и черновики сохраняются только в локальном хранилище браузера на этом устройстве. Удаление данных сайта удалит черновики. GitHub Pages является публичным хостингом: не помещайте личные данные, ключи или переписки в исходный код.

Перевод: доступны ГОТОВЫЕ двуязычные шаблоны. Произвольный текст не переводится автоматически.

Отправка: приложение открывает WhatsApp с подготовленным текстом, но отправка требует подтверждения пользователя.
